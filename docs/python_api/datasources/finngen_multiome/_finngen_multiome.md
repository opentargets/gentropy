---
title: FinnGen multiome
---

The [FinnGen multiome atlas](https://www.nature.com/articles/s41586-026-11078-2) profiles single-nucleus gene expression and chromatin accessibility in peripheral blood mononuclear cells from 1,108 Finnish donors.

We ingest the SuSiE fine-mapping of the single-cell cis-eQTLs for 33 Azimuth cell types (level 1, including all PBMCs together, and level 2). One study is defined per cell type and gene. Effect allele frequencies are taken from the cis-nominal summary statistics.
