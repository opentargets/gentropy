---
title: SLE-map
---

SLE-map ([Jang et al., 2026](https://doi.org/10.64898/2026.09.18.752560)) maps cis-eQTLs in 15 peripheral blood cell types, and in all cells together, of a systemic lupus erythematosus cohort, and fine-maps them with SuSiE on individual-level genotypes. The data is part of the Open Targets project OTAR2064.

We ingest one study per cell type and gene, of the study type `sceqtl`.
