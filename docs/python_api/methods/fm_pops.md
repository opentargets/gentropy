---
title: fmPops
---

Leave-one-chromosome-out kernel ridge regression behind the fmPops gene-level prior. The model
follows the polygenic priority score (PoPS):

- **Title:** Leveraging polygenic enrichments of gene features to predict genes underlying complex traits and diseases.
- **Authors:** Weeks, E.M., Ulirsch, J.C., Cheng, N.Y. et al.
- **Journal:** Nat Genet 55, 1267–1276 (2023).
- **DOI:** [10.1038/s41588-023-01443-6](https://doi.org/10.1038/s41588-023-01443-6)
