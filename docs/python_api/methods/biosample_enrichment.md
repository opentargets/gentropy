---
title: Biosample enrichment
---

Expression specificity of genes across tissues and cell types from the `baseline_expression` table of an Open Targets platform release, and a linear regression testing each disease's genes for being more specifically expressed in each biosample, adjusted for gene length and TSS density with standard errors clustered by 1 Mb region, as in the Open Targets platform biosample enrichment step. Used by the enriched biosample colocalisation L2G features.
